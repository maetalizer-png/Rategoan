Otak AI — Raget

Router intent yang mencoba lusinan mesin khusus sebelum jatuh ke jawaban umum: matematika (termasuk soal cerita), faktual dua-bahasa, follow-up kontekstual lintas giliran, toleransi typo, dan mode "terapkan" interaktif untuk kerangka berpikir seperti 5 Whys dan SWOT — bukan cuma definisi, tapi sesi tanya-jawab bertahap.

  • 236 profil tokoh publik terstruktur
  • 143 entri kuliner dunia per-region
  • Deterministik — jujur mengaku tidak tahu, bukan mengarang

Koleksi

Tiga tab: Tersimpan untuk pesan yang kamu tandai manual, Perpustakaan untuk semua yang diingat otomatis (catatan, fakta, file impor), dan Artefak untuk hasil kerja seperti draf email dan kartu negara.

Pitutur

Studio siaran audio yang membaca sumber data yang sama — PWA turunan yang bisa dipakai mandiri dan offline.

Privasi & Keamanan

Kunci Aplikasi (PIN) opsional, mode Server Kustom yang dimatikan secara default, dan seluruh riwayat chat bisa dicadangkan/dipulihkan sebagai file JSON milikmu sendiri.

Tampilan

Rapi di terang, tenang di gelap.

Kenapa Lokal

Server yang paling aman
adalah server yang tidak ada.

Setiap chat AI berbasis cloud berarti percakapanmu transit lewat jaringan orang lain. Rategoan menghapus langkah itu sepenuhnya — balasan dihasilkan dari pencocokan pola dan data terstruktur yang berjalan di JavaScript murni, langsung di browser.

Penyimpanan
IndexedDB di perangkat — tidak pernah dikirim ke server mana pun secara default.
Autentikasi
Masuk dengan Gmail hanya memakai alamat email untuk identitas lokal, tidak ada data yang diunggah.
Mode Server
Opsional dan nonaktif secara default — kamu yang memutuskan kapan data keluar perangkat.
Arsitektur
ES6 Modules murni, tanpa framework, tanpa langkah build — kode yang kamu baca adalah kode yang berjalan.
