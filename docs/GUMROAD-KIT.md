## Deskripsi

Capek bayar API LLM tiap bulan? Rategoan Starter Kit adalah kerangka chat AI
lengkap yang **jalan sepenuhnya di browser pengguna** — tidak ada server,
tidak ada API key, tidak ada tagihan bulanan yang membengkak seiring trafik.

**Yang kamu dapat:**
- ✅ Mesin balasan template engine yang bisa dikustomisasi total — ganti
  kepribadian, gaya bicara, dan basis pengetahuan cuma lewat file JSON, tanpa
  sentuh kode.
- ✅ Basis data dunia siap pakai: 1.500+ item (negara, kota, bahasa, makanan,
  wisata, tokoh, sains, olahraga, sejarah, dan banyak lagi) — bisa langsung
  dipakai atau diganti total sesuai niche produkmu.
- ✅ Fitur lengkap: riwayat obrolan, pengingat pintar, ekspor ke PDF/Markdown,
  pencarian terpadu lintas sumber, dan modul impor dokumen (PDF, Notion,
  Evernote, WhatsApp).
- ✅ PWA (Progressive Web App) — bisa di-install seperti aplikasi native, jalan
  offline, tanpa app store.
- ✅ Kode bersih, modular ES6, tanpa framework berat, gampang dipelajari.

**Cocok untuk:** developer yang mau bikin produk niche (asisten travel,
asisten UMKM, kuis edukasi, dst) tanpa mikirin biaya server/API sejak hari
pertama.

## FAQ

**Butuh API key OpenAI/Claude/dll?**
Tidak. Semua balasan dihasilkan dari mesin template lokal, tidak ada panggilan
API berbayar sama sekali untuk fitur inti.

**Bisa jalan offline?**
Ya, sepenuhnya — kecuali fitur opt-in (OCR, terjemahan, impor PDF/Notion) yang
butuh unduh paket sekali di awal, lalu jalan offline selamanya.

**Boleh dijual ulang produk turunan?**
Boleh, dengan lisensi Komersial. Menjual ulang kode sumber kit ini mentah-mentah
sebagai template tidak diperbolehkan — lihat `docs/LICENSE-KIT.md`.
