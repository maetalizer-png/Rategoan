# Skrip Demo Video — 60 Detik

Tujuan: tunjukkan Rategoan jalan tanpa internet & tanpa API key dalam waktu
singkat, cocok untuk video produk/landing page.

## Storyboard

**0:00–0:05 — Hook**
Layar: mode pesawat aktif di HP, lalu buka aplikasi Rategoan.
Teks overlay: "Chat AI ini nggak butuh internet sama sekali."

**0:05–0:15 — Bukti offline**
Ketik: "Selamat malam" → balasan kontekstual muncul instan.
Teks overlay: "Nggak ada server, nggak ada API key."

**0:15–0:30 — Kedalaman data**
Ketik: "apa ibukota negara yang punya makanan tom yum" (multi-hop).
Balasan: Thailand, Bangkok, Tom Yum muncul terstruktur.
Teks overlay: "1.500+ data dunia, semuanya di perangkat kamu."

**0:30–0:40 — Fitur privasi**
Buka Settings > tunjukkan tidak ada kolom API key sama sekali.
Teks overlay: "Data kamu nggak pernah keluar HP."

**0:40–0:50 — Fitur produktivitas**
Ketik: "ingatkan saya 30 menit lagi minum air" → reminder aktif.
Teks overlay: "Reminder, export chat, cari lintas dokumen — semua lokal."

**0:50–0:60 — CTA**
Layar: logo Rategoan + Jalanin side-by-side.
Teks overlay: "Starter kit-nya bisa kamu miliki. Link di bio."

## Catatan Produksi
- Rekam layar HP asli dalam mode pesawat untuk kredibilitas "no internet".
- Gunakan musik upbeat pendek, potongan cepat (2-3 detik per shot).
- Sertakan watermark kecil "100% offline, no API key" di pojok sepanjang video.
