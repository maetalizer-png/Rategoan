# Riwayat antarmuka

Rangkuman rilis 1.0 sampai 24.0. Detail lama yang sudah diganti tidak disimpan sebagai berkas terpisah.

| Rilis | Inti |
|---|---|
| 1.0–14.0 | Sasis obrolan, studio, dan fakta lokal |
| 20.0–22.0 | Jalur neural, preset 1.0B–2.0B, bukti rilis |
| 23.0 | Berkas Int4 di Hugging Face. Forward acak tidak dipakai untuk sapaan |
| 24.0 | Sapaan dan fakta dijawab di perangkat tanpa mengunduh 516 MB. SIMD128 menghitung dot |
