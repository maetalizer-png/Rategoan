# Skrip Konten TikTok — Build in Public Rategoan

Format tiap skrip: Hook (3 detik) → 3 Beat → CTA Follow.
Gaya: casual, jujur, build-in-public — nunjukkin proses, bukan cuma hasil.

---

## H1 — "AI Tanpa Internet & API Key" (Hari 1)

**Hook (0-3s):** *[layar HP, mode pesawat nyala]* "Gue lagi bikin AI chat yang jalan tanpa internet sama sekali. Nih buktinya."

**Beat 1:** Tunjukin mode pesawat aktif, buka aplikasi, ketik "halo" → balasan langsung muncul.

**Beat 2:** "Nggak ada server. Nggak ada API key OpenAI atau siapapun. Semua logic-nya jalan di browser kamu sendiri."

**Beat 3:** Zoom ke kode `ai-agent/` — "Ini otaknya, based on template + data, bukan model AI raksasa."

**CTA:** "Follow buat liat progressnya hari demi hari — target-nya sampe jadi produk beneran."

---

## H2 — "Disalamin Selamat Malam, Balesnya Mongolia" (Bug Nyata)

**Hook (0-3s):** *[layar chat]* "Gue tes AI gue sendiri, terus dia jawab ngaco kayak gini —"

**Beat 1:** Tunjukin screenshot bug: ketik "Selamat malam" → balesan malah nyebut bahasa Mongolia (bug asli dari sesi pengembangan).

**Beat 2:** "Ternyata dia salah ambil data — nyasar ke database bahasa dunia padahal cuma disuruh jawab sapaan biasa."

**Beat 3:** Tunjukin proses fix di kode, lalu test ulang → balesan udah bener.

**CTA:** "Ini yang gue maksud build in public — bug-nya juga gue tunjukin, bukan cuma yang mulus-mulus. Follow buat liat proses aslinya."

---

## H3 — "Data Gak Keluar Perangkat — Buktiin" (Privasi)

**Hook (0-3s):** "Semua orang bilang app-nya 'aman data lo', tapi bisa dibuktiin nggak? Gue coba buktiin punya gue."

**Beat 1:** Buka DevTools/Network tab di browser, ketik beberapa chat.

**Beat 2:** Tunjukin panel Network — nggak ada satu pun request keluar ke server manapun. "Kosong. Beneran kosong."

**Beat 3:** "Semua data chat, riwayat, sampe reminder — disimpen di localStorage HP kamu doang."

**CTA:** "Kalau kamu developer, coba buktiin app kamu sendiri kayak gini. Follow buat konten teknis lainnya."

---

## H4 — "Dites Pertanyaan Anak SD" (Demo Ringan)

**Hook (0-3s):** "Gue kasih AI buatan gue pertanyaan-pertanyaan level anak SD. Lolos nggak ya?"

**Beat 1:** Ketik "berapa 7 kali 8?" → jawab 56 bener.

**Beat 2:** Ketik "apa ibukota Indonesia?" → jawab Jakarta plus fakta tambahan (38 provinsi).

**Beat 3:** Ketik "hewan apa yang paling tinggi di dunia?" → coba, kalau ada di data jawab, kalau nggak, jujur bilang nggak tahu (bukan ngarang).

**CTA:** "Coba tantang AI ini di komen, pertanyaan apa yang menurut kamu bakal bikin dia bingung? Follow buat part 2."

---

## H5 — "Kakaknya: LLM dari Nol Pakai HP" (Hari ke-70)

**Hook (0-3s):** "Hari ke-70 gue coba bikin 'otak AI' dari nol, cuma modal HP. Ini progressnya."

**Beat 1:** Timelapse singkat: struktur folder awal yang masih berantakan → jadi modular rapi.

**Beat 2:** "Awalnya cuma bisa jawab template kaku. Sekarang udah bisa nalar berantai — misal tanya 'makanan khas negara yang ibukotanya Bangkok', dia bisa cari negaranya dulu baru jawab makanannya."

**Beat 3:** Demo cepat fitur multi-hop reasoning itu, hasil bener (Thailand, Tom Yum).

**CTA:** "Ini bukan LLM beneran ya, ini rule-based tapi didesain nalar berlapis. Follow biar nggak ketinggalan hari ke-71 dst."

---

## H6 — "Jalanin: Travel Offline dari 1.500+ Item Data"

**Hook (0-3s):** *[buka app Jalanin]* "Gue bikin app jalan-jalan yang isinya 1.500+ data dunia, dan ini jalan 100% offline."

**Beat 1:** Demo cari "Jepang" → kartu muncul: ibukota, mata uang, bahasa, makanan, wisata — instan tanpa loading.

**Beat 2:** Demo kuis "Tebak Dunia" — jawab beberapa soal, skor + streak harian muncul.

**Beat 3:** Demo flashcard sapaan bahasa asing + tombol dengar suara (text-to-speech bawaan HP, bukan API berbayar).

**CTA:** "Ini turunan dari project AI lokal gue sebelumnya, satu basis data dipakai berkali-kali. Follow buat liat produk turunan lain yang lagi gue bangun."

---

## H7 — "Bench 160 Kasus Hijau — Next: Jual Starter Kit"

**Hook (0-3s):** *[layar terminal, hasil test]* "160 kasus uji, semuanya hijau. Ini progress paling gede dari project AI lokal gue."

**Beat 1:** Scroll cepat hasil test yang PASS satu-satu, angka pass rate naik dari sesi ke sesi.

**Beat 2:** "Dari bug 'salah jawab bahasa Mongolia' pas awal, sampe sekarang bisa nalar multi-langkah, ini progress beneran, bukan demo doang."

**Beat 3:** Tunjukin folder `docs/` — starter kit siap dijual, lisensi, dan data pack terpisah.

**CTA:** "Next step gue jual starter kit-nya biar developer lain bisa mulai dari sini, nggak dari nol kayak gue. Follow biar nggak ketinggalan launch-nya."
