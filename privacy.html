Kebijakan Privasi Rategoan

Rategoan adalah aplikasi di perangkat Anda. Kebijakan ini berlaku untuk situs dan aplikasi Rategoan.

Tidak ada pengumpulan data

Rategoan tidak mengumpulkan data pribadi, rekaman suara, foto kamera, teks obrolan, maupun dokumen pengguna ke server eksternal mana pun.

Tidak dibagikan ke pihak ketiga

Data tidak dijual, tidak dibagikan, dan tidak dikirim ke penyedia kecerdasan buatan komersial.

Penyimpanan lokal terenkripsi

Obrolan, lampiran, dan artefak disimpan di perangkat Anda lewat IndexedDB. Jika PIN aktif, isi penyimpanan itu dikunci dengan AES-GCM 256.

Menghapus data

Di Pengaturan, Data, pilih Bersihkan Seluruh Data & Riwayat. Itu menghapus penyimpanan lokal dan kunci di perangkat ini.
