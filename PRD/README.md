# PRD Rategoan

Tiga dokumen roadmap pengembangan lanjutan, masing-masing satu sektor
kerja jelas — baca `PRD-ATURAN-KERJA.md` dulu sebelum mengerjakan yang
lain, aturan di situ berlaku untuk semua pekerjaan di repo ini.

- [`PRD-RAGET-TEMPLATE.md`](PRD-RAGET-TEMPLATE.md) — roadmap otak
  rule-based/retrieval: closed-loop feedback, auto-learning lokal
  (re-ranking, personalisasi), semantic search, tata kelola data.
- [`PRD-RAGET-NEURAL.md`](PRD-RAGET-NEURAL.md) — roadmap otak neural
  RATEGOAN sendiri dari 50M/100M/200M menuju 500M → 1B → 4B → 10B/20B/40B,
  syarat data/compute/inference tiap lompatan, makna jujur "belajar dari
  user"/"federated" di level model.
- [`PRD-ATURAN-KERJA.md`](PRD-ATURAN-KERJA.md) — aturan fokus per
  sektor: apa yang dilarang, apa yang warning, kriteria "selesai boleh
  pindah sektor".

Semua tiga PRD dirujuk dari [`docs/ARSITEKTUR.md`](../docs/ARSITEKTUR.md)
untuk peta teknis kondisi hari ini.
