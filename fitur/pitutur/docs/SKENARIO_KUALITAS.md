# Skenario uji kualitas Pitutur

Gunakan skenario ini untuk merasakan peningkatan kualitas (bukan cuma fitur baru).

## S1 — Dialog Dataries (paling cepat)

1. Sumber: **Dataries** on
2. Mode: **Dialog**
3. Saluran: Warta Hari Ini / Wisata / Sejarah
4. Susun Naskah → Putar

**Yang harus terasa:**
- Tanya tidak hanya "Wah, lanjut"
- Tanya menyentuh kata dari materi
- Warta menjembatani antar fakta ("Satu hal lagi…")
- Penutup mengajak praktik

## S2 — Diskusi tiga persona

1. Mode: **Diskusi**
2. Saluran: Kisah Tokoh atau Sains
3. Putar

**Yang harus terasa:**
- Kisah memasukkan analogi terkait materi
- Tanya menguji, Warta menjawab, Kisah memaknai
- Ritme bergantian, bukan monolog panjang

## S3 — Dokumen Baca berurutan

1. Unggah / tempel materi 300–800 kata
2. Mode materi: **Baca**
3. Mode siaran: **Dialog**
4. Putar dua kali (lanjut progres)

**Yang harus terasa:**
- "Bagian X dari Y"
- Jembatan antar bagian
- Tanya bereaksi ke isi chunk, bukan generik
- Siaran kedua melanjutkan, tidak mengulang dari nol

## S4 — Ringkasan (audio overview)

1. Mode materi: **Ringkasan**
2. Mode: Dialog
3. Putar

**Yang harus terasa:**
- Pembukaan "audio overview singkat"
- Hanya inti, lebih pendek dari Baca
- Cocok untuk review cepat

## S5 — FAQ

1. Mode materi: **FAQ**
2. Mode: Dialog atau Diskusi
3. Putar

**Yang harus terasa:**
- Tanya yang menguji, Warta menjawab dari materi
- 3 putaran tanya–jawab
- Bukan sekadar membacakan ulang seluruh dokumen

## S6 — Fokus topik

1. Mode materi: **Baca**
2. Isi Topik, mis. `olahraga` atau `pulau`
3. Susun Naskah

**Yang harus terasa:**
- Chunk dipilih yang relevan topik
- Bukan urutan halaman mentah

## Checklist kualitas (dengar + baca transkrip)

- [ ] Ada giliran Tanya di hampir setiap siaran Dialog
- [ ] Minimal satu pertanyaan mengacu ke isi (bukan hanya angguk)
- [ ] Tidak ada deretan "Hmm / Oke / Lanjut" tanpa fakta di antaranya
- [ ] Penutup actionable
- [ ] Bahasa satu warna (tidak campur EN/ID dalam satu baris konten)
